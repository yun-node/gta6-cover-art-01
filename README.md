Vice Cover Studio turns your own photos into GTA-style multi-panel poster cover art — 2, 3 or 4 panels with a Vice City sunset or neon colour grade and a big Anton caption — and exports a PNG in 1080×1080, 1080×1350 or 1920×1080, fully offline.

## Run it

```sh
node serve.ts
```
(open http://localhost:8080, load a photo, type a caption, export a PNG)
